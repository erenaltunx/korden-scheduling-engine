# Attribution and dataset licensing boundary

These **third-party benchmark instance data** are bundled solely to reproduce public
research calculations, independently of KORDEN's MIT-licensed program code.

- `ft06.txt`: Fisher and Thompson (1963), classic 6×6 job-shop instance;
  source mirror: https://github.com/tamy0612/JSPLIB/blob/master/instances/ft06
- `la01.txt`: Lawrence (1984), classic 10×5 job-shop instance;
  source mirror: https://github.com/tamy0612/JSPLIB/blob/master/instances/la01
- Reference solutions and instance context:
  https://scheduleopt.github.io/benchmarks/jsplib

KORDEN's MIT license does **not** assert ownership of these external instance
values, original publications, or their source repositories. The linked mirror
was found without an explicit root license in the locations checked; the exact
redistribution rights of these historical numeric instances have not been
independently established. Preserve attribution, and review permissions before
commercial reuse or broader redistribution. If necessary, distribute an importer
that loads authorized datasets instead of bundling raw third-party instances.

The time values in JSPLIB are **benchmark time units** and are not evidence of
real factory hours, financial savings, or time-on-machine observations.
