# Initial experiment report — OPTERA v0.1

## Experimental question

When scheduling five-order synthetic workshops with fixed process routes, alternative CNC machines, release dates, due-date priorities and occasional maintenance, can a validated MILP formulation improve weighted tardiness relative to Earliest Due Date dispatch?

## Reproducibility protocol

- Generator: `optera/generator.py`, 20 fixed seeds `0…19`, **five jobs and 15 operations per instance**.
- Machine set: CUT, CNC-A, CNC-B, PACK; CNC operations may choose either CNC machine.
- Jobs have deterministic integer processing times, release dates, weighted due dates.
- Solver: SciPy / HiGHS mixed-integer optimization, **2-second time limit per instance**.
- Baseline: transparent EDD job-level dispatch, not a global optimum.
- Output: `python benchmark_suite.py --count 20 --jobs 5 --time-limit 2`.
- All outputs passed independent machine capacity, maintenance and precedence checks.

| KPI | Measured result |

| Number of synthetic factories | 20 |

## Interpretation and limitations

1. **The 55.61% is a pooled reduction**, computed as `(214 - 95) / 214`, not the arithmetic mean of individual percentage improvements.
2. Eleven factory baselines already had zero weighted tardiness, so percentage improvement is undefined for those cases; they remain in the pooled total.
3. The results are based on small **synthetic** job-shop instances generated by OPTERA itself. They do not establish expected savings at a real factory and should not be described that way.
4. The seed generator uses a particular distribution of due-date slack and processing times. A credible portfolio study should also test established public benchmark families and harder, larger instances.
5. This version measures **weighted tardiness units**, not financial savings. Job weights are dimensionless priority multipliers.
6. Although 20/20 optimizations proved optimality for these small scenarios, larger instances may time out. A valid feasible schedule is not necessarily optimal.
7. The current objective lexicographically minimizes weighted tardiness and then makespan. It does not directly minimize cost, energy, or labor.

## What we can truthfully claim in a portfolio

> Built a local-first production scheduling optimizer using mixed-integer programming; tested 20 reproducible synthetic factory instances (300 operations), proving optimality in all 20 and reducing aggregate weighted tardiness by 55.61% versus an EDD dispatching baseline.

**Not a claim:** "Reduced real factory production cost by 55.61%."
